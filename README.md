# CPP 🖥️

## Overview 📚
This repository is a collection of modules from the 42 curriculum designed to teach and reinforce C++ fundamentals. These exercises were completed as part of my learning journey at 42, focusing on mastering the language and its core concepts through hands-on projects.

## Structure 📂
The repository is organized as follows:
- `CPP_00/` 🛠️: Basics and Object-Oriented Programming
- `CPP_01/` 🔧: Memory Management and References
- `CPP_02/` 🔄: Polymorphism, function overloading, canonical form classes
- `CPP_03/` 🧬: Inheritance and object hierarchy
- `CPP_04/` 🏗️: Polymorphism, abstract classes, interfaces
- `CPP_05/` ⚠️: Exception Handling
- `CPP_06/` 🔍: Casting
- `CPP_07/` 🧩: Templates
- `CPP_08/` 🗃️: STL Containers, iterators, algorithms
- `CPP_09/` 🚀: Advanced Containers
